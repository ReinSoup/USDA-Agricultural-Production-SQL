# Results

This folder contains selected outputs from the SQL analysis.

The results are intended to highlight the main findings from the project rather than reproduce every query output.

## Planned Results

Selected results will include:

* State-level production comparisons
* 2021 vs. 2022 production changes
* Largest production increases and decreases
* Percentage growth by state
* State shares of national production
* Cross-commodity comparisons
* Dominant commodity by state

The SQL used to generate each result can be found in the [`SQL`](../SQL/) folder.

## Results Format

Results may be added as:

* CSV files for structured output
* Screenshots of selected query results
* Tables or other visual summaries where they make the findings easier to understand

Only selected results will be included here to keep the repository focused and readable.
